소개

ABOUT THE ARCHIVE

수원의회 아카이브는 수원의 지역 대표들이 어떤 사람들이었는지를 기록하고 공유하기 위해 만든 디지털 아카이브입니다.

ARCHIVE LOG //
WHY //

누가 우리를 대표해 왔는가

지방의회는 '지역 토호의 이권 쟁탈장'이라는 혹평과 '풀뿌리 민주주의의 전당'이라는 칭송을 함께 받아 왔습니다. 이 아카이브는 평가에 앞서 사실을 모읍니다. 제한선거 시대의 자산가, 1950년대의 농업 종사자와 행정 경력자, 1991년 이후의 이주민 출신과 여성 의원까지 — 의원들의 사회적 배경을 따라가면 수원이라는 도시가 어떻게 바뀌어 왔는지가 드러납니다.

사진, 신문, 포스터, 선거자료, 통계표를 시기별 서류철로 정리하고, 각 자료에 소장처와 원문 쪽수를 밝혀 누구나 찾아보고 인용할 수 있도록 했습니다.

SOURCE //

『수원시의원으로 살다』

이 아카이브의 해설과 자료 정보는 『수원시의원으로 살다』 2장 「수원시의원들의 사회적 배경」(120~153쪽)을 바탕으로 합니다. 이 장은 1920년대 면협의회에서 2010년대까지 수원시의원들의 직업, 연령, 출신 지역, 학력을 추적하며 지역 정치의 변화를 읽어 냅니다.

각 자료의 원 출처는 수원박물관, 수원시의회, 중앙선거관리위원회, 『동아일보』, 『매일신보』, 개인 유족 등이며, 통계는 수원시의회 『수원시의회사』(2002)와 대수별 『의원총람』을 따랐습니다.

자료 기술 방식

모든 자료는 제목, 시기, 유형, 소장·출처, 인물, 주제어, 원문 쪽수, 식별자로 기술했습니다. 이 항목은 Dublin Core(dcterms) 요소에 대응하며, 원본 데이터는 Omeka S에서 관리하고 공개 사이트는 GitHub Pages로 배포합니다.
